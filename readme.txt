关于新增配置文件：
此为添加新的河闸配置文件时所需要遵守的基本格式：
***请将文件名命名为对应河闸的名称***
***随后请在相对应超参数的冒号后面添加对应的数值***
***需要注意的一点是，由于Pyhon在读入文件时所需要的特殊事项，在任何一个冒号左侧的位置你都应该以双引号修饰你的键，而值则可以根据原本的数据类型直接定义***
{
  "Hb": ,
  "g": ,
  "b": ,
  "alpha": ,
  "holeSubmergeCoefficient": ,//如果淹没系数为一固定值，那么请直接填写，如果需要根据上下游水位差进行计算，请使用字典形式对对应关系进行定义
  "C0_map": ,//定义时遵循和淹没系数一样的规则
//此为上游断面水位-断面面积对应表
  "data": {
    
  }
}

关于批量处理：
批量处理的数据应当参考input.csv文件的格式进行定义,其中需要计算的数据仅保留列名,数据栏目保持留空即可,建议你将需要计算的数据直接写在input.csv内部
点击批处理按钮之后，在文件选取页面点击你想要计算csv文件,程序会自动的把需要计算的数据结果补齐.
